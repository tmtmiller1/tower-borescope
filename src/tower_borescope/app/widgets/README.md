# widgets

Shared sidebar widgets and layout helpers used by the window panels and dialogs.

## Files

- `__init__.py`: package docstring listing the modules.
- `labeled_slider.py`: slider with a title, a live value label and double-click reset, configured by a `SliderSpec`.
- `layout.py`: group boxes, rows, columns, scroll areas, small labels, and buttons and checkboxes that refuse keyboard focus.
- `html_text.py`: escaping of text placed into Qt rich text.
